# PitStop Garage — car service website

A complete website for a single garage: customers register, add vehicles, describe a problem, see an estimated spend, track the job live (Booked → Repairing → Repaired → Testing → Ready → Delivered) and get digital bills. The owner has a separate portal with analytics, searchable records and a bill generator.

**Stack:** Next.js 15 (App Router, server actions) · Prisma 6 · SQLite · plain CSS (cream theme with an animated gears-and-parts background that builds a car).

## Run it

```bash
npm install
cp .env.example .env      # skip if .env already exists
npm run setup             # prisma generate + create the SQLite DB + seed services, plans and demo data
npm run dev               # http://localhost:3000
```

For production: `npm run build && npm start`.

To start with an empty garage (no demo customers): `SEED_DEMO=0 npm run seed`.

## Pages

Customer side

- `/` home with services (Repairing, Washing, Modification, Maintenance), how it works and plans
- `/register` step 1 personal details, step 2 vehicle details
- `/dashboard` all vehicles, jobs in the garage, add more vehicles (`/vehicles/new`), vehicle history (`/vehicles/[id]`)
- `/book` write a query, get an estimated spend for that vehicle type, book
- `/track/[id]` delivery-app style live tracker (refreshes every 8 seconds)
- `/bills`, `/bills/[id]` bills generated by the garage for the customer's vehicles (printable)
- `/plans` monthly or yearly plans, applied per vehicle

Owner portal (`/owner`, owners only)

- Analytics: revenue by month and category, top services, outstanding dues, vehicles by make, jobs by stage
- Records: search vehicles (reg. number, make, model, customer name/phone), jobs, bills and customers
- Jobs: update status with a note (the customer sees it instantly), edit work items
- Generate bill: pick a customer and vehicle (or start from a job), add line items from the catalogue, discount, GST, mark paid
- Services & prices: edit prices and the keywords that drive estimates
- Owner access: grant/revoke owner role by email, or share `/owner-join` plus the `OWNER_ACCESS_CODE` so someone can create an owner account

## How the estimate works

`lib/estimate.js` matches the customer's text against each service's keywords (edit them in the owner portal), then multiplies the base price (set for a hatchback) by the vehicle type: Sedan ×1.15, SUV ×1.35, Luxury ×1.8. The shown range is −10% to +25% of the price to allow for parts. If nothing matches, an inspection is suggested.

## Make it yours

- Name, phone, address, GSTIN, GST rate: `lib/config.js`
- Colours: CSS variables at the top of `app/globals.css`
- Background parts: `components/AmbientBG.js`; the car that assembles in the hero: `components/CarAssembly.js`
- Database schema: `prisma/schema.prisma` (switching to Postgres later means changing the datasource provider and URL)

## Notes

- Money is stored as whole rupees. Payments are recorded by the owner (no online payment gateway yet).
- All database access goes through Prisma (`lib/db.js`).
